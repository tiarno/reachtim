Most of these started the same way: I lost a week to something — a PDF that
wouldn't validate, LaTeX that refused to paginate, a server I couldn't see
inside — and wrote up whatever finally worked, mostly so I'd be able to find it
again.

They're from 2014 to 2020, carried over from the old blog. I've left the code
alone, so a few of them show their age. The ideas hold up better than the
version numbers do.
